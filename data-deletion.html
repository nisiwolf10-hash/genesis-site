מחיקת מידע

Genesis הוא עוזר אישי פרטי, והמידע היחיד שנשמר בו הוא של בעל השירות.

כדי למחוק את כל המידע שנשמר (שיחות, זיכרון, תזכורות):

  1. שלחו לבוט את ההודעה: "מחק את כל המידע שלי".
  2. המידע יימחק ממסד הנתונים של השירות, ותתקבל הודעת אישור.

מספרים וחשבונות אחרים אינם נשמרים כלל, ולכן אין מידע למחוק עבורם.

Data Deletion Instructions

Genesis is a private personal assistant; the only data it stores belongs to its owner. To delete all stored data (conversations, memory, reminders), send the bot the message "delete all my data". The data is removed from the service's database and a confirmation is sent. Messages from any other number or account are never stored, so there is no data to delete for them.
